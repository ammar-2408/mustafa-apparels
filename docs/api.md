# API

The apps talk to the server in two ways:
- **Server Actions** for form mutations from our own UI (sign-up excluded — Better Auth owns that).
- **Route Handlers** (`app/api/**/route.ts`) for auth, uploads, search suggestions, cross-app revalidation and machine-readable files.

## 1. Conventions

**Every server action / route handler follows this order:**
1. Parse and validate input with a Zod schema from `packages/validators` (`safeParse`; reject unknown keys with `.strict()`).
2. Authenticate/authorize: `await requireUser()` or `await requireAdmin()` from `packages/auth` (throws → 401/403).
3. Rate-limit if listed below.
4. Call `packages/core` — no business logic in the route file.
5. Revalidate caches / write audit log.
6. Return a typed result.

**Result type for server actions**
```ts
type ActionResult<T> =
  | { ok: true; data: T }
  | { ok: false; error: { code: ErrorCode; message: string; fieldErrors?: Record<string, string[]> } };

type ErrorCode = 'VALIDATION' | 'UNAUTHENTICATED' | 'FORBIDDEN' | 'NOT_FOUND'
               | 'CONFLICT' | 'RATE_LIMITED' | 'INTERNAL';
```
Messages are safe to show users; never include stack traces, SQL or whether an email exists.

**Route handler errors** use the same shape as JSON with matching HTTP status (400, 401, 403, 404, 409, 429, 500).

## 2. Storefront (`apps/web`)

### Server actions
| Action | Input (Zod) | Auth | Rate limit | Returns |
|---|---|---|---|---|
| `submitInquiry` | `{ productId?, name (2–80), email, phone (PK format, optional if email), message (≤2000), website (honeypot, must be empty) }` | none (user linked if logged in) | 5 / 10 min / IP | `{ inquiryId }` |
| `toggleWishlist` | `{ productId }` | user | 60 / min / user | `{ saved: boolean }` |
| `updateProfile` | `{ name, phone? }` | user | 20 / hour / user | `{ user }` |
| `deleteAccount` | `{ confirm: "DELETE", password }` | user (fresh session) | 3 / hour / user | `{ ok }` then sign out |

### Route handlers
| Route | Method | Purpose | Auth | Notes |
|---|---|---|---|---|
| `/api/auth/[...all]` | GET, POST | Better Auth: sign-up, sign-in, sign-out, session, verify email, forgot/reset password | — | Better Auth built-in rate limits on |
| `/api/search/suggest?q=` | GET | Top 6 product/category suggestions | none | 30 / min / IP; `q` 2–60 chars; `Cache-Control: s-maxage=60` |
| `/api/revalidate` | POST | Clear storefront cache tags after admin changes | HMAC | See §4 |
| `/sitemap.xml` | GET | Generated by `app/sitemap.ts` | none | Published products + active categories + static pages, absolute URLs, `lastModified` |
| `/robots.txt` | GET | Generated by `app/robots.ts` | none | Disallow `/account`, `/api`, `/search`; link sitemap. Preview envs: disallow all |
| `/llms.txt` | GET | Plain-text Markdown guide for AI assistants | none | See `docs/design.md` §8.4 |
| `/opengraph-image` (+ per route) | GET | Dynamic OG images (`next/og`) | none | 1200×630, product photo + name + price |

### Page data (Server Components, via `core`)
`getHomeData()`, `listProducts({ category?, page, sort, filters })`, `getProductBySlug(slug)`, `resolveSlugRedirect(entity, slug)`, `searchProducts({ q, page, filters })`, `getSiteSettings()`, `getWishlist(userId)`, `listMyInquiries(userId)`.

## 3. Admin (`apps/admin`)

All actions call `requireAdmin()` first (role `admin` + 2FA-verified session). All mutations write `audit_log` and trigger storefront revalidation.

### Server actions
| Action | Input | Revalidates |
|---|---|---|
| `createProduct` | product fields + `images[]` ({ publicId, url, alt, width, height, sortOrder, isPrimary }) | `products`, `category:<slug>` |
| `updateProduct` | `{ id, ...fields }` — slug change writes `slug_redirect` | `products`, `product:<id>`, old+new category |
| `setProductStatus` | `{ id, status }` | same as update |
| `duplicateProduct` | `{ id }` (copy saved as draft) | — |
| `archiveProduct` / `restoreProduct` | `{ id }` | `products` |
| `reorderProductImages` | `{ productId, imageIds[] }` | `product:<id>` |
| `deleteProductImage` | `{ imageId }` — also deletes from Cloudinary | `product:<id>` |
| `createCategory` / `updateCategory` / `reorderCategories` / `setCategoryActive` | category fields | `categories`, `products` |
| `setInquiryStatus` | `{ id, status }` | — |
| `updateSiteSettings` | `{ key, value }` (validated per key) | `settings` |

### Route handlers
| Route | Method | Purpose | Notes |
|---|---|---|---|
| `/api/auth/[...all]` | GET, POST | Better Auth for admin (sign-in + 2FA only; sign-up disabled) | Sign-in rejects non-admins with a generic error |
| `/api/upload/sign` | POST | Returns Cloudinary upload signature | Admin only; 30 / min; signs `folder=products`, `allowed_formats=jpg,png,webp`, max 10 MB, timestamp ±5 min |

## 4. `POST /api/revalidate` contract

```http
POST {WEB_URL}/api/revalidate
Content-Type: application/json
X-Timestamp: 1730000000
X-Signature: hex(hmac_sha256(REVALIDATE_SECRET, timestamp + "." + body))

{ "tags": ["products", "product:abc123", "category:formal"] }
```
- Reject if signature invalid (constant-time compare), timestamp older than 5 minutes, body > 2 KB, or tags not matching `^(products|categories|settings|product:[\w-]+|category:[\w-]+)$`.
- Responses: `200 { revalidated: [...] }`, `401`, `400`.

## 5. Validation schemas (examples)

```ts
// packages/validators/product.ts
export const productInput = z.object({
  name: z.string().trim().min(2).max(120),
  slug: z.string().regex(/^[a-z0-9]+(?:-[a-z0-9]+)*$/).max(140),
  description: z.string().max(5000).default(''),
  price: z.number().int().min(0).max(10_000_000),
  compareAtPrice: z.number().int().positive().nullable(),
  categoryId: z.string().min(1),
  sizes: z.array(z.enum(['XS','S','M','L','XL','XXL','Custom'])).max(10),
  colors: z.array(z.string().trim().min(1).max(30)).max(12),
  fabric: z.string().max(60).optional(),
  availability: z.enum(['in_stock','low_stock','out_of_stock','made_to_order']),
  status: z.enum(['draft','published','archived']),
  featured: z.boolean(),
  attributes: z.record(z.string(), z.unknown()).default({}),
  seoTitle: z.string().max(70).optional(),
  seoDescription: z.string().max(160).optional(),
}).strict()
  .refine(p => p.compareAtPrice == null || p.compareAtPrice > p.price, {
    path: ['compareAtPrice'], message: 'Must be higher than price',
  });
```

## 6. Versioning

Internal APIs (server actions) change with the code. If a public JSON API is ever added (e.g. for a mobile app), put it under `/api/v1/` with OpenAPI docs in this file.
